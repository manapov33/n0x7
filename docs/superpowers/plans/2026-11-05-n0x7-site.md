# Сайт студии N0X7 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Опубликовать сайт-портфолио N0X7: 3D-журнал на тёмном столе, который посетитель листает сам, с обычной запасной страницей.

**Architecture:** Статичный сайт. Вся логика (навигация, изгиб, камера, загрузка) живёт в чистых модулях с юнит-тестами, Three.js только рисует их результат. Запасная страница генерируется из тех же данных при сборке и лежит в HTML, 3D-режим включается поверх неё.

**Tech Stack:** Node 20+, Vite, TypeScript (strict), Three.js, Vitest, Playwright, sharp, `@fontsource` (Cormorant, Manrope, JetBrains Mono).

**Spec:** `docs/superpowers/specs/2026-11-05-n0x7-site-design.md`

## Global Constraints

- Язык сайта русский: `<html lang="ru">`, цены в рублях.
- Точные тексты: подпись «сайты и приложения на заказ», кнопка «Обсудить проект», подсказка «листайте», пометка работ «концепт».
- Без сервера, базы данных и формы заявки. Контакты: ссылка на Telegram и телефон.
- Шрифты подключаются локально через `@fontsource`, без запросов к внешним сервисам.
- Запасная страница показывается, если WebGL недоступен, сцена не инициализировалась, текстуры не загрузились или включено уменьшение движения.
- Заглушки содержат слово `PLACEHOLDER`. Публикация с ними запрещена, это проверяет `npm run check:release`.
- Страницы журнала: 1200×1600 px, WebP, не больше 250 КБ каждая.
- Папка проекта ещё не под git: `git init` выполняется в задаче 1. Каждый коммит заканчивается строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- Быстрые повторные команды (серия кликов, удержание стрелки): журнал не выходит за границы и приходит на верный разворот. Тесты в задачах 2 и 5.
- Инерция скролла на тачпаде: один жест листает одну страницу, а не весь журнал. Тест в задаче 5.
- Жест прерван (`pointercancel`, отпускание за окном): страница сама доходит до устойчивого положения. Тест в задаче 5.
- Поворот телефона или изменение окна: журнал снова вписывается в экран без искажений. Тесты в задачах 4 и 7.
- Потеря WebGL-контекста во время просмотра: посетитель видит запасную страницу, а не чёрный экран. Тест в задаче 4.

**Interfaces:**
- Consumes: `Spread` из задачи 1.
- Produces:
```ts
type Sheet = { front?: string; back?: string };
export function buildSheets(spreads: Spread[]): Sheet[];
export const TURN_SECONDS = 0.7;
export interface BookModel {
  readonly spread: number; readonly sheetCount: number;
  next(): void; prev(): void; goTo(spread: number): void;
  beginDrag(dir: 1 | -1): boolean; moveDrag(fraction: number): void;
  endDrag(velocity: number): void; // velocity: доля листа в секунду
  update(dt: number): void; progress(sheet: number): number; isSettled(): boolean;
}
export function createBookModel(spreadCount: number): BookModel;
export function sheetPoint(u: number, p: number): { x: number; z: number };
export function shadowOpacity(p: number): number;
```

Разворот `k` значит, что листы `0..k-1` перевёрнуты. Листов столько же, сколько разворотов; последний не переворачивается. `progress`: 0 — лист лежит справа, 1 — слева.

- [ ] **Step 1: Написать падающие тесты**

```ts

expect(s).toHaveLength(5);

expect(s[0].back).toBe(site.spreads[1].left);
expect(s[1].front).toBe(site.spreads[1].right);
expect(s[4].back).toBeUndefined();

// model
const m = createBookModel(5);
m.prev(); expect(m.spread).toBe(0);
for (let i = 0; i < 20; i++) m.next();
expect(m.spread).toBe(4);                       // границы при серии команд
m.update(10); expect(m.isSettled()).toBe(true);
expect(m.progress(3)).toBe(1); expect(m.progress(4)).toBe(0);
m.goTo(1); m.update(10); expect(m.progress(1)).toBe(0);

const d = createBookModel(5);
expect(d.beginDrag(-1)).toBe(false);            // с обложки назад нельзя
expect(d.beginDrag(1)).toBe(true);
expect(d.beginDrag(1)).toBe(false);             // второй жест не начинается

f.beginDrag(1); f.moveDrag(0.3); f.endDrag(1); f.update(10);
expect(f.spread).toBe(1);                       // рывок, переворот

// bend
expect(sheetPoint(1, 0).x).toBeCloseTo(1); expect(sheetPoint(1, 0).z).toBeCloseTo(0);
expect(sheetPoint(1, 1).x).toBeCloseTo(-1); expect(sheetPoint(1, 1).z).toBeCloseTo(0);
expect(sheetPoint(0, 0.5)).toEqual({ x: 0, z: 0 });
expect(sheetPoint(1, 0.5).z).toBeGreaterThan(0);
// для p из 0..1 все z >= 0, длина ломаной по u равна 1 с точностью 1e-2
expect(shadowOpacity(0)).toBeCloseTo(0); expect(shadowOpacity(0.5)).toBeCloseTo(0.45);
```

- [ ] **Step 2:** `npx vitest run tests/unit/model tests/unit/sheets tests/unit/bend`. Ожидается FAIL.
- [ ] **Step 3:** Реализовать. Каждый лист движется к своей цели со скоростью `1 / TURN_SECONDS`, поэтому несколько листов могут лететь одновременно. Порог завершения жеста: доля больше 0,5 или `velocity` больше 0,5 в сторону движения (при `velocity` меньше −0,5 жест откатывается, даже если доля большая). Изгиб считается численным интегрированием за 24 шага:

```ts
// угол сегмента s в [0, 1]; при p = 0 и p = 1 изгиб исчезает
const a = (s: number) => clamp(Math.PI * p + 0.6 * Math.sin(Math.PI * p) * (s - 0.5), 0, Math.PI);
// x(u) = ∫ cos a(s) ds, z(u) = ∫ sin a(s) ds, s от 0 до u
```

`shadowOpacity(p) = 0.45 * Math.sin(Math.PI * p)`.
