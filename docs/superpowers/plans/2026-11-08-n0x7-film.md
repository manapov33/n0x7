# Сайт N0X7 v2: 3D-фильм по скроллу — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Превратить сайт из журнала с ручным листанием в непрерывный фильм, которым управляет скролл: стол → журнал → ныряние в работу → ролик → выныривание → следующая работа → услуги → контакты.

**Architecture:** Чистая функция таймлайна переводит прогресс скролла в состояние фильма (камера, страницы, кадр ролика, надписи). Сцена Three.js только применяет это состояние. Ролик работы — последовательность кадров WebP на «экране» поверх открытого разворота; первый кадр совпадает со страницами разворота, поэтому переход без склейки.

**Tech Stack:** Vite, TypeScript strict, Three.js, Vitest, Playwright, sharp, системный ffmpeg (для экспорта кадров).

**Spec:** `docs/superpowers/specs/2026-11-06-n0x7-film-design.md` (v2), действующие части `docs/superpowers/specs/2026-11-05-n0x7-site-design.md`.

## Global Constraints

- Язык русский, тексты: подпись «сайты и приложения на заказ», кнопка «Обсудить проект», пометка «концепт», подсказка первого экрана «скролльте».
- Без сервера и формы; контакты Telegram и телефон; шрифты локально; без внешних запросов.
- Запасная страница при: нет WebGL2, ошибка сцены, сбой или зависание загрузки, уменьшение движения. Не менять её поведение.
- Скролл назад проигрывает фильм в обратную сторону: состояние зависит только от прогресса, не от истории.
- Отрисовка только при изменениях (как сейчас).
- Импорты с явным `.ts`. Каждый коммит заканчивается строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- Быстрый скролл или прыжок через несколько сцен: показывается ближайший готовый кадр или страница, а не пустота. Тест в задаче 4.
- Перезагрузка страницы посередине фильма (браузер восстанавливает скролл): сцена сразу соответствует позиции. Тест в задаче 2.
- Телефонная адресная строка меняет высоту окна: длина фильма и позиция не прыгают. Тест в задаче 3.
- Изменение размера окна посередине: та же сцена, камера вписана. Тест в задаче 2.
- Медленная сеть: кадры ролика ещё грузятся — виден первый кадр, фильм не блокируется. Тест в задаче 4.

```ts
type SceneId = 'table' | 'open' | 'dive' | 'play' | 'surface' | 'turn' | 'services' | 'contacts';
type SceneSpec = { id: SceneId; screens: number; work?: number };   // work — индекс работы 0..2
export function buildScenes(workCount: number): SceneSpec[];
export const SCREENS: Record<SceneId, number>;
type Camera = { x: number; y: number; h: number };                  // h — высота над столом
type FilmState = {
  scene: SceneId; sceneT: number;            // 0..1 внутри сцены
  camera: Camera;
  coverOpen: number;                         // 0..1, сдвиг закрытой обложки
  sheets: number[];                          // прогресс каждого листа 0..1
  spread: number;                            // открытый разворот 0..spreads-1
  work: { index: number; frame: number; screen: number } | null; // frame 0..1, screen 0..1 видимость экрана
  overlay: Record<string, number>;           // id надписи → непрозрачность 0..1
};
type FilmInput = { scenes: SceneSpec[]; spreadCount: number; aspect: number };
export function computeFilm(progress: number, input: FilmInput): FilmState;
export function sceneStart(scenes: SceneSpec[], index: number): number; // прогресс начала сцены
export function totalScreens(scenes: SceneSpec[]): number;
```

Порядок сцен для 3 работ: `table, open, [dive, play, surface, turn]×3 без последнего turn, services, contacts`. Длины в экранах: `table 0.8, open 0.8, dive 0.4, play 1.2, surface 0.4, turn 0.4, services 0.8, contacts 0.8` (итого около 10.4). Работа `k` открыта на развороте `k + 1`; `turn` после работы `k` переворачивает лист `k + 1`. После последней работы `turn` ведёт к развороту услуг (`spreads - 1`).

Камера: `table` — высота `2.2 × fitCamera(aspect,'spread')`, к концу `table`/`open` опускается до `fitCamera(aspect,'spread')`; `dive` — к высоте, при которой разворот 6×4 закрывает весь экран (cover: `max(4/2/tan, 6/2/(tan×aspect))` без запаса); `play` держит её; `surface` возвращает к spread; `contacts` поднимает к высоте `table`. Сглаживание переходов — smoothstep внутри сцены.

Надписи (`overlay`): `hero` (видна в `table`, гаснет к середине `open`); `work-k` (растёт в первой половине `play`, держится, гаснет в `surface`); `services` (в `services`); `contacts` (в `contacts`).
